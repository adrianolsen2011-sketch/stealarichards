Steal a Richards

En enkel nettleserbasert demo laget raskt. Åpne `steal-a-richards.html` i nettleseren for å spille.

Denne versjonen bruker Three.js for en enkel 3D-opplevelse.

Kontroller:
- Piltaster eller WASD for å bevege deg.
- Stjel den gule ruten (Richard) for poeng.
- Unngå de røde fiendene.

Kjør:
- Dobbeltklikk filen `steal-a-richards.html` eller serve mappen med en enkel HTTP-server.

Tips: Hvis nettleseren blokkerer lokale filer, start en enkel server i mappen, f.eks.:

```powershell
python -m http.server 8000
```

Åpne deretter `http://localhost:8000/steal-a-richards.html`.

Ideer for videreutvikling:
- Legg til lydeffekter og animasjoner.
- Poengtavle og høyeste poeng.
- Flere nivåer og power-ups.
